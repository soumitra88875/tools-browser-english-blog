## Why do bars hide when you scroll?

Tools Browser is designed in a way that reduces distraction while reading a webpage.

When you —

- scroll down  
  → **Top bar and Bottom navigation bar hide automatically**
- scroll up  
  → **They automatically show again**

The main reason is very simple.

To provide a **full screen webpage reading experience**,  
so that bars do not keep disturbing you while reading content.

This is not a bug.  
This is an intentional system in Tools Browser.

---

## What actually happens when you use Two Finger Touch?

This is where most of the confusion happens.

Many times, without realizing it,  
we touch the webpage using **two fingers**.

In Tools Browser, this means —

- As soon as two fingers touch the screen, **Top bar and Bottom navigation bar get hidden**
- Even if you scroll up or down, the bars do not show again
- The entire webpage goes into **full page / full screen mode**

This system is created to provide a  
**completely distraction-free reading experience**.

After that, what does the user usually notice?

👉 Content can be read fully from bottom to top  
👉 Bottom text or buttons are no longer covered  

From this perspective, the feature is actually very good.

## The actual rule is very simple

When the bars are hidden —

- Touch the same webpage again using **two fingers**
- Then **Top bar and Bottom navigation bar will appear again**

In very simple words —

- Two finger = Hide  
- Two finger again = Show  

This is a toggle system.

## But where is the real problem?

The real problem starts here.

After using two finger touch —

- Menu gets hidden  
- New tab open option gets hidden  
- In short, the entire search bar becomes hidden  

Many users want these options to be **visible all the time**.

That means the user wants —

- Bottom content to be clearly visible  
- But Top bar menu and tab options should not disappear  

This is where the full two finger hide system  
does not feel comfortable for many users.

---

## The only practical solution: Hide only the Bottom Navigation Bar

This problem already has a solution inside Tools Browser.

This is the most balanced option.

With this —

- Bottom content stays fully visible  
- Top bar menu and tab options remain available  

### How to hide only the Bottom Navigation Bar

1. Open Tools Browser  
2. Go to **Settings**  
3. At the top, you will see an option called **Hide Bottom Bar**  
4. Enable (tick) that option  

Follow the screenshot below —

## What actually happens after enabling this option?

After enabling this setting —

- Bottom navigation bar stays permanently hidden  
- Scrolling up or down will not show the Bottom bar again  
- Two finger touch will not bring back the Bottom bar  
- Top bar will behave normally (show / hide on scroll)

As a result —

- Content can be read clearly from bottom to top  
- Menu, tools, source, and tab options remain available  
- You still get a full screen feeling  
- Full control remains in the user’s hands  

This is the best setup for most users.

## When is it best to hide the Bottom Navigation Bar?

- While reading blogs or articles  
- While reading long content  
- When using educational websites  
- When bottom buttons of a website get covered  
- When you want menu and tools to stay visible  

Many users permanently use Tools Browser this way.
