## 🛠️ The Tool We’ll Use (Tools Browser)

For this, we’ll use a special **Android Browser**—

👉 **Tools Browser**

This is not a normal browser.  
It includes powerful tools that allow you to—

- View **Live Source Code**
- Inspect the **HTML Body**
- View the **Full Page Source Code** if you want  

All of this **directly from your mobile phone**.

---

## 📌 Step-by-Step: How to View Source Code on Mobile

### 🔹 Step 1: Open Tools Browser

First, open **Tools Browser** on your phone.

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/IMG_20251230_094637.jpg)

---

### 🔹 Step 2: Load Any Website

Now open any website, for example—

- Facebook  
- YouTube  
- Amazon  
- Or any site you like  
- Here, I opened Facebook

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/facebook_home.jpg)

---

### 🔹 Step 3: Click the Tools Button

After the website loads, click the **Tools Button** from the bottom or menu bar.

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/IMG_20260104_205607.jpg)

---

Once clicked, you’ll see—  
👉 **Multiple powerful tools together**

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/Screenshot_2025-12-30-09-56-14-415_com.soumitra.toolsbrowser.jpg)

---

### 🔹 Step 4: Select the Inspect Tool

From the tools list, click on  
👉 **Inspect Tool**

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/IMG_20251230_095927.jpg)

---

### 🔹 Step 5: View the Source Code Inside the Body Tag

Once Inspect Tool opens—

- You can directly see the **Live Source Code inside the HTML Body tag**
- This is the exact code that users see visually  

👉 **This is extremely useful for beginners.**

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/Screenshot_2025-12-30-10-02-51-159_com.soumitra.toolsbrowser.jpg)

---

## 🔎 Want the Full Website Source Code? (Advanced)

Sometimes the Body code isn’t enough.  
👉 You may need the **Complete Source Code** of the website.

### 🔹 Step 6: Open the Source Page

While the Source Page is open,  
👉 Click the **Menu (⋮)** button at the top.

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/IMG_20251230_100824.jpg)

---

### 🔹 Step 7: Select “All” from Show Options

- Click on **Show Options**

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/IMG_20251230_101118.jpg)

---

- Then select **All**

---

![Thumbnail](https://raw.githubusercontent.com/soumitra88875/tools-browser-blog-image/main/view_source_code_blog/IMG_20251230_101250.jpg)

---

Now you’ll see—  
👉 **The complete source code of the entire website**
